# Serene Seasons Horizon

A configurable four-season calendar prototype for Horizon 26.3.

## Included

- Four seasons and three sub-seasons, with configurable season length
- No always-visible year/season HUD text
- Craftable Season Calendar: shapeless recipe using one paper and one clock
- Right-click a clock to read the current year, season, sub-season and day
- `/season` calendar command and seasonal crop-fertility helper

## Install

Add `SereneSeasons-Horizon-0.2.0.hnmod` through Horizon's native mod manager.
To enable crafting, install `Serene-Calendar-26.3.zip` into the target world's
`datapacks` folder, then run `/reload` or re-enter the world. The recipe output
is a renamed clock; right-clicking a clock displays the calendar.

## Compatibility

- Minecraft Java Edition 26.3
- Horizon revision `a46ce6898bd72016e061aaec1afc1375b384deac`
- Native hook API 2

## Status

This is an early prototype, not a complete recreation of the Fabric mod. It has
not been compiled or tested in the Horizon launcher. Horizon native mods are
unrestricted native code; review before installing.
